🚀 Manoj M Kadaramandalgi | GenAI Engineer Portfolio

This is the official repository for the personal portfolio of Manoj M Kadaramandalgi, a GenAI Engineer specializing in scalable LLM applications, RAG pipelines, and backend microservices.

The portfolio is designed as a fast, single-page application to showcase core skills, professional experience, and key projects in a modern, dark-themed interface.

✨ Features

Single-Page Application (SPA): Contains all content (HTML, CSS, JavaScript/Game Logic) in one self-contained index.html file.

Fully Responsive: Designed using Tailwind CSS for optimal viewing on desktop, tablet, and mobile devices.

Key Projects Highlighted: Detailed summaries of two core GenAI projects:

Dynamic AI Agent Workflow System

RAG Search & Question Answering Engine

Interactive Game: Includes a fully functional "Flappy Developer" game built with pure JavaScript on a Canvas.

Clear Contact Information: Easy access to email, LinkedIn, and resume download.
